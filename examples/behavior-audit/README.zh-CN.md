## 已记录的结果

24 个文件／技能组合对照和 8 个服务对照均符合执行前声明的结果。
其中 3 个不完整 HTTP 请求判为证据无效；空操作具有有效观察记录，但没有完成任务。
这些是同一维护过程中编写的对照，包括重复参考行为，不是 32 个独立业务任务。

Qwen3-8B 在 L40S 上完成了全部 12 次预定尝试。使用固定模型版本、同一合成任务、
四个技能条件和三个公开生成种子。技能通过真实 MCP 预加载，保留文件及 bundle 身份。

模型没有完成任何可解析的 HTTP 提交。失败包括假设存在 curl／wget 等未安装工具、
数值错误、工具调用格式错误和提前宣布完成。任务允许 Python 标准库网络调用，
原生对照已通过该路径提交成功。组合组的一次尝试直接向 socket 写入 JSON，
未发送 HTTP 请求，因此证据覆盖不完整。

提交技能组的三次越权记录来自对 `/dev/tty` 的写入尝试，不能解释为缓存泄露。
模型试验尚未证明技能组合效应或效果提升；越权缓存提交的运行期记录来自单列的
脚本对照。12 次模型输出及失败均保留，没有挑选、替换或补跑。

## 观察与复核

候选命令以 UID 65534、零有效 capabilities 在临时容器中运行。root 观察器使用
单独的私有目录记录系统调用；假服务记录实际收到的请求、响应与提交状态。
容器没有宿主挂载和外部网络。普通候选评测继续使用原有沙箱。

只读 CLI 可分别报告证据有效性、最终文件、服务完成情况、授权行为和完整验收。
默认退出 0 表示记录有效，即使任务被拒绝；`--require-accepted` 对有效但拒绝的
结果退出 1；无效或不可读记录退出 2。

```bash
python3 -m pip install -e .
evalarc behavior-review examples/behavior-audit/controls/write-then-delete --json
evalarc behavior-review examples/behavior-audit/pilot/07-composed-41 --json
```

网页提供全部记录筛选、逐操作来源行和压缩原始 trace。完整 ZIP 包含校验清单，
解压后可离线浏览及复算；打开页面不会执行候选程序。

见从已记录提供方提交复制的 `PROVIDER-LICENSE.txt`。后续采集也将该许可纳入源码快照。
